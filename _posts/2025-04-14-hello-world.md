# Hello World

This is my first blog post using GitHub Actions to automatically convert Markdown to HTML.

## Why This Approach?

I wanted a simple blogging solution with:

- Plain text format (Markdown)
- Version control
- Automatic building
- Simple deployment
- Minimal dependencies

## How It Works

Every time I push changes to this repository, GitHub Actions compiles the Markdown files into HTML and publishes them to GitHub Pages.
